# E-commerce Customer Conversion & Journey Funnel Analysis

## Project Overview
This project analyzes e-commerce customer behavior, conversion funnel performance, and purchasing patterns to identify opportunities to improve conversions and business performance.

The analysis explores customer journeys from product discovery to purchase, along with revenue trends, device performance, traffic sources, payment methods, and product categories.

## Objectives
- Analyze customer journey and funnel conversion rates.
- Identify potential drop-off points in the purchasing process.
- Evaluate revenue and order performance.
- Compare customer behavior across devices and traffic sources.
- Analyze payment methods and product category performance.
- Generate actionable, data-driven business recommendations.

## Tools & Technologies
- **Python:** Data cleaning, exploratory data analysis, and visualization.
- **SQL:** Data querying and business analysis.
- **Power BI:** Interactive dashboards and reporting.
- **Tableau:** Data visualization and analytical reporting.

## Project Structure
- `01_Raw_Data/` – Raw e-commerce datasets.
- `02_Cleaned_Data/` – Cleaned datasets.
- `03_SQL/` – SQL table creation and analysis queries.
- `04_PowerBI/` – Power BI reports and dashboard files.
- `05_Analysis/` – Python scripts and analytical outputs.

## Key Areas of Analysis
1. **Conversion Funnel Analysis:** Examine customer progression through funnel stages.
2. **Revenue Analysis:** Evaluate revenue trends and order performance.
3. **Device Analysis:** Compare customer activity and conversion across devices.
4. **Traffic Source Analysis:** Examine performance by acquisition channel.
5. **Payment Analysis:** Compare purchasing behavior by payment method.
6. **Product Category Analysis:** Identify category-level sales patterns.

## Business Value
The findings can help identify friction in the purchase journey, understand differences in customer behavior, and support data-driven decisions to improve the e-commerce experience.

## Project Status
Portfolio project. Dashboard documentation, visualizations, and findings can be expanded as the analysis progresses.
